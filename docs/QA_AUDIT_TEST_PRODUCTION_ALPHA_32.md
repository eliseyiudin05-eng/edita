# Проверка KIVRONIX — test-production v2.0.0-alpha.32

Дата: 17 сентября 2026 года  
Исходный commit: `f5b0cd7aa2f8d9bcbcac08adddfdc871e1626b31`

## Краткая оценка готовности

Публичные страницы, регистрация, сборка и защищённые API готовы к продолжению закрытого тестирования. В Академии исправлены преждевременный показ аттестации, небезопасный клиентский запасной доступ по `localStorage` и неверное состояние урока после сбоя необязательной публикации.

До публичного запуска нужен отдельный архитектурный этап серверной защиты HTML закрытых страниц: сейчас API и изменения данных защищены, однако сервер отдаёт разметку урока до клиентского перенаправления гостя на вход.

## Проверенные разделы

- главная, метаданные, 404 и защитные заголовки;
- вход, восстановление и смена пароля;
- регистрация монтажёра, блогера и компании;
- учебный маршрут, урок, аттестации трёх уровней и выпускной экзамен;
- правила последовательности уроков и аттестаций;
- тексты бренда и ошибки авторизации;
- клавиатурный фокус, подписи основных форм и уменьшение движения;
- словарь терминов внутри уроков;
- ответы закрытых API без авторизации;
- production-сборка всех 88 маршрутов.

Исключено из текущей проверки — юридическая и финансовая части будут дорабатываться отдельно.

## Академия

- подтверждено три уровня: НАЧАЛО, БАЗА, PRO;
- аттестация закрыта до завершения обязательных уроков;
- следующая аттестация требует предыдущую;
- выпускной экзамен требует все обязательные уроки и три аттестации;
- сервер остаётся источником истины для прогресса;
- необязательная публикация работы больше не отменяет успешное завершение урока в интерфейсе.

## Мобильная версия и доступность

Проверены CSS-границы 650, 700, 760, 780, 800, 850 и 900 пикселей, перенос длинных текстов, одно-колоночный словарь, формы и кнопки. Добавлены видимый фокус и уменьшение анимации. Полный визуальный прогон матрицы 320–1920 пикселей не выполнен: браузерный движок и `agent-browser` отсутствовали в среде. Это остаётся обязательным шагом перед публичным запуском.

## Браузеры и HTTP

- `/`, `/login`, `/signup/editor`, `/signup/creator`, `/signup/business`, `/forgot-password` — HTTP 200;
- несуществующая страница — HTTP 404;
- `/api/lessons/progress`, `/api/academy/assessments`, `/api/profile/learning-preferences` без токена — HTTP 401;
- приватные страницы получают `X-Robots-Tag: noindex, nofollow`;
- ответы получают `X-Frame-Options: SAMEORIGIN`;
- в проверенных HTML нет EDITA, KIVROX и KIVRONIKS.

## Риски перед закрытым тестированием

1. Нужны реальные тестовые аккаунты каждой роли и подключённое тестовое окружение Supabase для полного сценария регистрации, подтверждения почты, повторного входа и сохранения данных.
2. Нужна визуальная проверка заданной матрицы экранов в Chromium, Safari/WebKit и Firefox.
3. Нужна проверка загрузки реальных видео разных размеров, длительности и кодеков.

## Риски перед публичным запуском

1. Перенести авторизацию закрытых страниц на серверную cookie-сессию, не полагаясь на клиентский `AuthGate`.
2. Добавить и проверить Content-Security-Policy без нарушения Supabase, изображений, видео и ИИ-запросов.
3. Провести отдельную юридическую и финансовую проверку; эти части в текущем изменении не редактировались.

## Подтверждение границ

Юридические документы, оферты, договоры, политики, согласия, налоги, оплата, банковские интеграции, безопасная сделка, эскроу, вывод средств, возвраты, комиссии, тарифы, цены, финансовые расчёты и платёжная логика не изменялись.
